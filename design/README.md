# 界面视觉稿（专业金融终端风）

`ui_mockup.html` 是单文件高保真稿，浏览器直接打开即可。三个屏幕：

| 入口 | 屏幕 |
|---|---|
| 默认 | 自选股简报（行情条 + 简报正文 + 事件时间线） |
| `#analysis` | 个股深度分析（KPI + K 线 + 成交量 + 表格视图） |
| `#paywall` | 付费墙弹窗 |

## 设计 token

| 角色 | 值 |
|---|---|
| 页面底 | `#0a0c10` |
| 面板 / 抬升面 | `#11151c` / `#161b24` / `#1c2330` |
| 描边 / 网格 | `#232a36` / `#1b212b` |
| 主文字 / 次文字 / 弱文字 | `#e8edf5` / `#a7b1c2` / `#8a94a6` |
| 涨 | `#e66767` |
| 跌 | `#199e70` |
| 强调（品牌/升级） | `#e0a33a` |

## 颜色规则（已验证，改色前请重跑验证）

- 涨跌这对颜色在 `#11151c` 上过 WCAG：涨 5.66:1、跌 5.37:1，正文可用。
- 色盲区分度 ΔE 6.5（protan），落在「6–8 警告带」：**必须带二级编码**。稿子里统一用
  `▲ / ▼` + 正负号 + 「涨/跌」文字，任何地方都不要只靠红绿色。
- 上涨 K 线用空心、下跌用实心，形态本身也是一层编码。
- 网格线用实线细线，不用虚线；不用双 Y 轴（成交量是独立面板，共享 x 轴）。
- 表格中的数字用 `tabular-nums`，大号价格数字用默认比例数字。

## 落到 Streamlit 的注意事项

- `st.markdown(..., unsafe_allow_html=True)` **不会执行 `<script>`**，稿子里的悬停、
  切换、弹窗在实现时换成 Streamlit 原生能力：K 线用 Plotly（自带十字光标与 tooltip），
  屏幕切换用 `st.sidebar.radio`，付费墙用 `st.dialog`。
- 稿子里的卡片结构可以直接搬成 markdown 片段；行情条用 `st.columns(3)`，
  简报页主区用 `st.columns([1.6, 1])`。
- 全局样式集中在 `ui/styles.py`：把现在的紫色渐变标题、圆角卡片换成上表的 token，
  并统一 `.stApp` 背景色与描边。
- Streamlit 默认主题要在 `.streamlit/config.toml` 里同步成深色底，否则组件间会闪白。
